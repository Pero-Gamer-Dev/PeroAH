# PeroAH - Auction House Plugin

A Spigot/Paper plugin for managing player auctions.

## Features

- Create and manage auctions
- Bid on items
- Mail system for completed auctions
- Economy integration
- GUI-based interaction
- Admin commands

## Installation

1. Download the latest JAR file
2. Place it in your server's `plugins/` directory
3. Restart your server
4. Configure `config.yml` as needed

## Configuration

See `config.yml` for available options.

## Building

This project uses Maven. To build:

```bash
mvn clean package
```
